# DiPlay v0.2.72 — 音视频渲染稳定性优化、有线连接阻塞修复与API 17兼容增强

## 更新内容

### 1. 媒体与音视频稳定性优化（#214, #170）
- **导航 Opus 音频通道修复**：针对 Android 4.x 老版本车机上 Opus 导航语音静音问题进行适配与通道修正，确保导航播报正常出声。
- **倒车影像切回黑屏修复**：修复倒车切回 CarPlay 主界面时 SurfaceView 重新绑定导致的黑屏冻结问题，平滑恢复画面显示。
- **AAC 硬件解码输出退化软解回退**：检测到平台硬解输出异常退化时，自动切换到内置软解，彻底消除特定车机芯片上的爆音或静音。

### 2. 有线 CarPlay 握手阻塞与时序修复（#211, #205, #137）
- **消除连接卡界面与通道阻塞**：修复有线连接过程中多通道竞争与配对信任时序竞争，彻底解决特定机型卡在连接界面的问题。
- **已信任设备重枚举优化**：当 iPhone 已经处于 CarPlay 模式枚举时，跳过冗余的重枚举握手流程，加速启动。
- **看门狗触发快照补全**：在触发 `NO_AIRPLAY_TCP` 看门狗重置时，保留底层 VPN 实例引用，完整记录 lwIP TCP 状态快照，杜绝状态丢失。

### 3. 老旧系统底层兼容增强（#213, #172）
- **Android 4.2 / API 17 USB 兼容**：在 API 17 系统上自动适配 4 参数版本的 `bulkTransfer`，消除底层传输报 `NoSuchMethodError`。
- **单芯片热点硬件冲突规避**：在打开车机便携式热点前先安全关闭当前 Wi-Fi，兼容不支持并发 AP/STA 模式的老款车机 Wi-Fi 芯片。

### 4. 外置 USB 蓝牙适配器建链加固（#206）
- **优化 iAP2 SDP 服务查询**：修复 SDP 查询与链路认证加密建链超时，加固 L2CAP 数据帧接收队列，提升无线连接握手成功率。
