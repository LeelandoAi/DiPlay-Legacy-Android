# DiPlay v0.2.63 — 开机热点重试与主线稳定性优化

## 更新内容

### 1. 热点开机自启重试与稳定性
- **延迟补试机制**：车机冷启动过程中，若系统 Wi-Fi 芯片或热点服务尚未完全就绪导致首次启动内置热点失败，后台将在 60 秒后自动补试一次，大幅提升点火自动互联成功率。

### 2. 悬浮球交互与页面导航
- **桌面快捷返回**：悬浮球快捷点击逻辑改走系统 Launcher 桌面图标入口，彻底解决无活跃 CarPlay 会话时点击悬浮球黑屏且只能退入设置页的问题。

### 3. 会话保护与崩溃防御
- **AirPlay 媒体链路保护**：针对 iAP2 控制通道出现短暂静默的场景，若当前仍有 AirPlay 媒体（音频/视频）正常传输，则不误判为链路断开，避免误复位导致播放中断。
- **ROM 兼容性防御**：解决部分老款车机定制 ROM 上将底层 Socket 转换为 Closeable 产生的类型转换崩溃，提升会话关闭与清理时的稳定性。

### 4. 网络诊断与探针增强
- **无线入网嗅探**：通过被动 mDNS 嗅探和网络入网探针，精确区分手机 DHCP 分配失败与手机端 mDNS 静默无广播，提供更有针对性的诊断信息。
- **蓝牙有界探针**：增强 SDP 与 RFCOMM 有界探针检测，并在诊断报告中更详尽地采集系统蓝牙通信日志。
