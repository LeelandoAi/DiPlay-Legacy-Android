# DiPlay v0.2.63 — 外置 USB 蓝牙适配器与多 USB 口车机兼容

## 更新内容

### 1. 用户态外置 USB 蓝牙协议栈 (Pure Android USB Host)
- **免系统蓝牙/免 Root**：直接通过 Android USB Host API 实现 HCI 传输协议、L2CAP 通道、RFCOMM 会话、SDP 服务发现及配对代理，支持无车载内置蓝牙或车载内置蓝牙损坏的老款车机通过外置 USB 蓝牙 Dongle 开启无线 CarPlay。
- **广泛芯片与适配器兼容**：原生支持 Realtek (RTL8761B / RTL8761BUV，如绿联 CM390)、CSR (CSR8510 A10)、Broadcom 等主流芯片组及 TP-Link UB500、ASUS USB-BT500 等适配器。
- **固件智能加载与回退**：自动检测 Realtek 等芯片是否缺少固件，分片上传固件补丁并自适应波特率；若本地无固件资产，平滑回退至芯片出厂 ROM 尝试初始化，避免进程死锁挂起。
- **配对与链路密钥持久化**：完整支持 Just Works 自动配对与 Numeric Comparison 弹窗配对验证，支持 Link Key 本地安全持久化存储，重连免重复配对。

### 2. 车机多 USB 口外设共存（全志 T3、MTK 等）
- **外设智能排他与防误判**：针对老款车机常年插着行车记录仪（USB 摄像头/UVC）与音乐 U 盘的多接口场景，基于 USB 设备类与接口描述符过滤，精准排除 `USB_CLASS_VIDEO` (0x0E)、`USB_CLASS_MASS_STORAGE` (0x08)、`USB_CLASS_HUB` (0x09) 等，即使同厂商制造的摄像头也绝不误判为蓝牙适配器。
- **设备热插拔容错隔离**：精准跟踪活跃连接的蓝牙 Dongle；当行车记录仪在车辆点火、颠簸或紧急录像重新枚举（产生 Detached 广播）时，不中断正常运行的蓝牙会话。
- **多设备候选发现**：支持轮询多候选 USB 设备，优先激活已获取权限的蓝牙适配器，避免盲取首项导致的权限死锁。

### 3. 主线稳定性更新与合并
- **热点自启重试**：开机自启动热点失败后增加 60 秒延迟自动补试机制，提高点火自连成功率。
- **悬浮球桌面导航**：悬浮球快捷入口改走桌面图标，修复无活跃会话时点击黑屏只能进设置的问题。
- **通信容错与健壮性**：修复定制 ROM 上 Socket 转 Closeable 崩溃；移植 iAP2 静默时保护 AirPlay 媒体链路等稳定性修复。
