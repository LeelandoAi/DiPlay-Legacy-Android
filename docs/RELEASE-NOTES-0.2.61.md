# DiPlay v0.2.61 — Android 4.2 兼容与无线蓝牙启动修复

## 更新

- Android 4.2 兼容：移除对 API 21 才提供的加密异常类的直接引用，修复 AirPlay 加密类加载时触发 VerifyError 的问题，保留认证标签校验失败时的拒绝行为。
- 连接界面：Android 4.2/4.3 改用兼容的窗口附着检测，避免调用 API 19 才提供的方法而崩溃。
- 视频解码：Android 4.2 的 H.264 首帧同时携带 SPS/PPS 参数，兼容忽略独立格式参数的旧解码器。
- 无线启动：蓝牙关闭时先尝试开启混合蓝牙适配器，并最多等待 3 秒；仍未开启时保留明确的失败提示，改善部分车机没有蓝牙开关入口的场景。
- 连接诊断：增加有线 16 步、无线 12 步全链路阶段日志，帮助定位 USB、蓝牙、配对、服务发现和 AirPlay 会话的连接断点。
- 日志查看：诊断区新增“查看日志”按钮，无需先保存文件即可打开报告，生成期间显示加载状态。
- 回归验证：补充旧 Android 上的加密往返与篡改密文拒绝测试。
