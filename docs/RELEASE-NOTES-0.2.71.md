# DiPlay v0.2.71 — 外置USB蓝牙建链诊断增强

## 更新内容

### 外置 USB 蓝牙适配器关键建链诊断写入导出日志（#206）
- **SDP iAP2 RFCOMM 服务查询诊断**：在使用外置 USB 蓝牙适配器（例如在未内置原生蓝牙协议栈的全志 T3 等车机上）进行无线 CarPlay 握手时，将 SDP 查询结果（成功解析到的 channel 编号或协商失败原因及回退默认通道）完整写入用户导出日志。
- **ACL 逻辑链路状态追踪**：对 ACL 连接建立事件（`ACL created`）以及复用已建链路事件（`ACL reused`）实时记录设备地址与 connection handle，便于定位配对成功后蓝牙链路无响应或意外断开的原因。
- **支持现场导出诊断**：上述日志统一归集至 `UsbBtLog`，在车机端“设置 → 诊断 → 保存诊断报告”即可一键导出包含外置蓝牙底层协议交互的完整日志。
