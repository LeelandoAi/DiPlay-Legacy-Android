# DiPlay v0.2.62 — 有线连接重试修复

## 更新

- 有线重试：连接失败或重建桥接器时保留 VPN 服务管理的 TUN，避免下一次重试因 `Already closed` 失败。
- 资源释放：继续关闭旧 NCM USB 桥接器，TUN 在 VPN 服务销毁时统一关闭。
